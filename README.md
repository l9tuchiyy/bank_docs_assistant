# Помощник по регламентам и документам

Веб-приложение для работы с внутренними документами: оно находит положения в базе знаний, помогает подготовить проект по модулю, подсказывает маршрут согласования и проверяет загруженные документы перед визированием.

## О проекте

Проект выполнен в рамках хакатона по кейсу **«Чат-бот по работе с документами»**. Цель кейса — создать помощника для сотрудника, который не только находит положения Инструкции, но и помогает решить рабочую задачу: подготовить документ по модулю, определить маршрут визирования, обработать замечания или проверить готовый проект.

Решение является прототипом и демонстрационным проектом для портфолио. Оно не является официальным сервисом Банка России и не предназначено для работы с реальными конфиденциальными документами без доработки мер безопасности.

## Что умеет

- Отвечать на вопросы по Инструкции, Матрице визирования, методическим рекомендациям и модульным документам.
- Показывать источник каждого ответа и честно сообщать, когда ответа в базе нет.
- Уточнять недостающие данные: вид документа, тему, адресата, подписанта и другие реквизиты.
- Подбирать модуль документа, выдавать бланк или собирать черновик через диалог.
- Проверять загруженные PDF, DOCX, TXT и Markdown-файлы: незаполненные поля, остатки шаблонов, единообразие наименований и даты.
- Подсказывать маршрут визирования с учётом Матрицы.
- Давать структуру реестра замечаний.
- Загружать и удалять материалы базы знаний через админ-панель `/admin`.
- Работать в двух режимах: детерминированные выдержки из базы или ИИ-режим с Qwen 2.5 через OpenRouter.

## Как это устроено

```text
Вопрос сотрудника
       │
       ├── определение сценария: вопрос / модуль / проверка проекта
       ├── поиск по базе знаний (BM25)
       │      └── низкая релевантность → честный отказ без выдуманных требований
       ├── ответ с источниками или уточняющий вопрос
       ├── ИИ-режим: Qwen 2.5 формулирует ответ только по найденным фрагментам
       └── проверка ссылок в ответе ИИ перед показом пользователю
```

Основные каталоги:

| Путь | Назначение |
|---|---|
| `app/services/dialog.py` | Диалоговые сценарии, уточнения, защита от нерелевантных запросов |
| `app/services/kb.py` | Загрузка и разбиение базы знаний на положения |
| `app/services/retrieval.py` | Поиск BM25 |
| `app/services/checker.py` | Детерминированная проверка проекта документа |
| `app/services/llm.py` | Qwen 2.5 через OpenRouter и опциональная локальная Ollama |
| `knowledge_base/` | Нормативные материалы и размеченные положения |
| `templates/` | JSON-шаблоны модульных документов |
| `static/` | Интерфейс чата и админ-панель |

## Быстрый старт

Требования: Python 3.11+ и `pip`.

```bash
git clone https://github.com/<your-username>/<your-repository>.git
cd <your-repository>

python -m venv .venv
```

Активируйте окружение.

**Windows PowerShell**

```powershell
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux**

```bash
source .venv/bin/activate
```

Установите зависимости и запустите приложение:

```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Откройте:

- приложение: `http://127.0.0.1:8000`;
- админ-панель: `http://127.0.0.1:8000/admin`;
- интерактивная документация API: `http://127.0.0.1:8000/docs`.

Без ИИ-ключа приложение полностью работает в режиме поиска и цитирования положений базы знаний.

## ИИ-режим: Qwen 2.5 через OpenRouter

ИИ-режим не заменяет поиск: Qwen получает только уже найденные фрагменты базы и должен проставить ссылки на них. Если ссылки не проходят проверку, приложение не показывает ответ модели и использует безопасный режим.

### 1. Получите ключ OpenRouter

1. Зарегистрируйтесь или войдите на [OpenRouter](https://openrouter.ai/).
2. Откройте страницу [Keys](https://openrouter.ai/keys).
3. Создайте новый API key и скопируйте его. Ключ показывается полностью только при создании.
4. При необходимости пополните баланс/настройте лимиты в аккаунте: доступность и стоимость модели зависят от условий OpenRouter.

По умолчанию используется модель `qwen/qwen-2.5-72b-instruct`. Актуальный идентификатор модели, цены и доступность смотрите на [странице модели в OpenRouter](https://openrouter.ai/qwen/qwen-2.5-72b-instruct).

### 2. Создайте `.env`

Скопируйте пример:

**Windows PowerShell**

```powershell
Copy-Item .env.example .env
```

**macOS / Linux**

```bash
cp .env.example .env
```

Откройте `.env` и заполните значения:

```dotenv
# Токен для /admin: замените на длинную случайную строку
ADMIN_TOKEN=change-this-to-a-long-random-value

# Ключ OpenRouter. Никогда не публикуйте его в GitHub.
OPENROUTER_API_KEY=sk-or-v1-...
OPENROUTER_MODEL=qwen/qwen-2.5-72b-instruct
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1

# Локальный Ollama отключён; это не влияет на ИИ-режим OpenRouter.
LLM_ENABLED=0
```

Перезапустите `uvicorn`, откройте интерфейс и включите переключатель **«ИИ-режим Qwen 2.5»** в верхней панели.

## Администрирование базы знаний

1. Запустите приложение и перейдите на `/admin`.
2. Введите значение `ADMIN_TOKEN` из `.env`.
3. Загрузите PDF, DOCX, TXT или MD размером до 10 МБ.
4. Файл сохраняется в `knowledge_base/admin_uploads/`, база автоматически перечитывается и начинает участвовать в поиске.

Пользовательские загрузки, логи и материалы, добавленные через админку, исключены из Git с помощью `.gitignore`.

## Локальный ИИ без внешнего API

Вместо OpenRouter можно запустить Ollama:

```bash
ollama pull qwen2.5:7b-instruct
```

В `.env` задайте:

```dotenv
LLM_ENABLED=1
OLLAMA_MODEL=qwen2.5:7b-instruct
OLLAMA_URL=http://localhost:11434
```

Этот режим используется для локальной генерации; облачный переключатель в интерфейсе по-прежнему предназначен для OpenRouter.

## Безопасность и ограничения

- Проект демонстрационный. Для промышленного использования требуются SSO, серверное разграничение прав, антивирусная проверка вложений, журналирование в защищённом контуре и аудит обработки персональных данных.
- ИИ может ошибаться; финальные решения по визированию и регистрации должен подтверждать сотрудник, уполномоченный по документообороту.
- Логотип и название Банка России в прототипе используются исключительно для демонстрационного макета.
